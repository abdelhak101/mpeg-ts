# MPEG-TS Explorer

An educational project focused on understanding, parsing, and demultiplexing **MPEG-2 Transport Streams (MPEG-TS)** to explore their use in custom media player development.

## Objectives

- Understand MPEG-TS packet structure and binary format.
- Parse TS headers, adaptation fields, PAT, PMT, and PES.
- Extract audio and video elementary streams.
- Understand PID management, PCR, PTS, DTS, and synchronization.
- Explore audio/video codec decoding.
- Implement and compare MPEG-TS processing in **Python, C, and JavaScript**.
- Build the foundation for a custom media player.

## Learning Resources

1. [ISO/IEC 13818-1:2000 — MPEG-2 Systems](https://ocw.unican.es/pluginfile.php/2825/course/section/2777/iso13818-1.pdf)
2. [An Introduction to MPEG-TS — TSDuck](https://tsduck.io/docs/mpegts-introduction.pdf)

## Development Roadmap

1. TS packet parsing.
2. PSI tables and descriptors.
3. PES parsing and reconstruction.
4. Audio/video demultiplexing.
5. Timing and synchronization.
6. Codec integration and media player development.

## Languages

- **Python:** Learning, prototyping, and testing.
- **C:** Low-level parsing and performance.
- **JavaScript:** Browser integration and playback.

## Final Goal

Develop a practical understanding of MPEG-2 Transport Streams and build reusable components for parsing, demultiplexing, and eventually playing MPEG-TS media streams.
